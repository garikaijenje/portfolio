# Garikai Jenje — Portfolio

Personal portfolio website for Garikai Jenje, Senior Software Engineer.

## Live Site

Hosted on GitHub Pages.

## Overview

A static, single-file portfolio built with pure HTML, CSS, and JavaScript. Dark theme with emerald green accents, smooth scroll-reveal animations, and a responsive layout.

### Sections

- **Hero** — Name, role, social links
- **Core Skills** — Categorized skill tags (Languages, Databases, Cloud, Quality, Other)
- **Experience** — Full timeline of professional experience (2015–Present)
- **Mobile Apps** — Published apps with screenshots (Access Forex, BantuSphere, Dosery, ELMS)
- **Websites** — Client websites built across industries
- **DevTools Passion** — Wazza desktop app screenshots and description
- **Education** — Academic background
- **Connect** — GitHub, LinkedIn, X/Twitter links

## Local Usage

Open `index.html` directly in your browser.

## Project Structure

- `index.html` — Single-file site with inline HTML, CSS, and JavaScript
- `images/` — App screenshots and Wazza desktop app images
- `preview.png` — OG/social preview image
- `.nojekyll` — Ensures GitHub Pages serves the site as a plain static project

## Deployment

This repository is configured for GitHub Pages:

1. Push to `main`
2. Open `Settings -> Pages`
3. Under `Build and deployment`, set `Source` to `GitHub Actions`

No build step required — the repository contents are deployed directly.
